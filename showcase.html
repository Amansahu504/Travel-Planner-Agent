Architecture

Four tiers, one rule: the host never touches a tool.

How a request flows

"Plan 7 days in Japan, find hotels, estimate cost, explain the policy."

The single hardest path — one request that needs both specialists at once.

01
Route
The host reads the request and recognises it spans both planning and operations.
02
Delegate to both agents in one turn
Over A2A: the itinerary to Agent 1, hotels + budget + policy to Agent 2.
03
Retrieve & ground
Agent 1 pulls destination facts from the knowledge server; grades whether they're good enough; falls back to web search and rewrites its query if not.
04
Validate the budget — in code, not the LLM
Cost lines are extracted, then summed in Python and compared to the target. The model can't claim a $3,450 plan fits $3,000.
05
Critique & revise
A critic reviews the plan; if it fails, it's revised (this is also the budget optimiser) and re-checked. Capped at 3 rounds so it always finishes.
06
Merge & return
The host stitches both agents' replies into one consolidated answer — itinerary, costs, hotels, policy — with sources and assumptions disclosed.

What makes it notable

The decisions behind the demo.

Correctness

Budget maths in Python

LLMs happily declare over-budget trips "within budget." Totals are computed deterministically in code, and the critic is told to trust that verdict — so the plan is always internally consistent.

Reliability

Three loop caps

An agent that revises its own work can loop forever. Independent limits on retrieval retries, revision rounds, and graph recursion guarantee it always terminates and discloses any open issues.

Extensibility

Swappable flight provider

A provider interface behind the booking tools made live Duffel a drop-in: real search + booking when a key is set, automatic fallback to sample data otherwise. The agents never know which is active.

Retrieval

Corrective RAG

A 12-node LangGraph pipeline grades its own retrieval, falls back to web search, and rewrites weak queries — grounding every recommendation in a real source rather than guessing.

Resilience

Free-tier survival

Gemini caps embeddings at 100/min. The vector build is throttled, resumable, and every model call retries with exponential backoff, so a rate-limit spike never sinks the run.

Delivery

Tested & shippable

~200 automated tests (unit + live integration), Docker Compose with service-name networking and health-gated startup, structured logging, and a one-command local launcher.

Real vs sample data — stated honestly

What's live, what's synthetic, and why.

Flights are genuinely booked live in a safe test mode. Hotels stay synthetic on purpose — there is no free hotel-booking API; every real one needs a commercial contract.
